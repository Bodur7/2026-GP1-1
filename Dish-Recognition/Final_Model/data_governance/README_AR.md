# المرجع الدائم لمراجعات المستخدم

قرارات المستخدم ملزمة للمشروع كله، وليست ملاحظات مؤقتة لتجربة واحدة.
الملف المعتمد: `human_label_registry.json`، وقارئه المشترك:
`src/dish_identifier/human_labels.py`.

استورد السجل جميع القرارات الـ295 من ملف Food-101 المكتمل، مع قرارات هذه
المحادثة ومصادرها. لكل صورة بصمة SHA-256 وسجل تاريخي للقرار. لا تُعتمد
اقتراحات النماذج على أنها مراجعات بشرية.

- RELABEL: الاسم الذي حدده المستخدم هو المرجع، حتى عند نسخ الصورة أو تغيير اسمها.
- KEEP: الحفاظ على الاسم الذي أبقاه المستخدم، وإلغاء أي اقتراح آلي مخالف.
- UNSURE: غير محسوم؛ لا يُستخدم هدفًا مؤكدًا للتدريب أو لحساب صحة التصنيف.
- EXCLUDE_UNUSABLE: يُستبعد من أهداف التدريب والمقاييس، وتُحفظ الصورة والأدلة الأصلية.

المطابقة ببصمة الصورة، لا باسم الملف أو المجلد. أي اختلاف بين البصمة المعلنة
وبصمة الملف يُوقف العملية. غياب السجل أو عدم دعم الاسم المصحح يُوقف المسار
المعني دون تخمين أو رجوع صامت للاسم القديم.

## العمل المستقبلي

عند تصحيح المستخدم صورة، استخدم `scripts/record_human_label.py` لتسجيلها مع
نص التصحيح ومصدره. أي مراجعة بشرية لاحقة مخالفة تتطلب توثيقًا صريحًا بأنها
تراجع القرار السابق؛ لا يُمحى التاريخ. أعد بناء التقارير المشتقة فقط.

لملف نتائج أو manifest جديد استخدم `scripts/reconcile_human_labels.py`؛ يحتفظ
بجميع الصفوف والأعمدة الأصلية ويضيف مرجع التصحيح وأهلية احتساب المقاييس.
قارئات التدريب المدمجة تستخدم القارئ المشترك وتُبقي المستبعد وغير المحسوم في
سجل التدقيق، خارج الأهداف المؤكدة.

كل مسار جديد أو سكربت مستقل قديم يجب ربطه بالقارئ المشترك قبل تشغيله، كما
تُلزم تعليمات `AGENTS.md`. عند النقل لخادم آخر، تُنقل مكتبة القارئ والسجل
مع المشروع. لا تكفي ملفات الصور وحدها.

تبقى تنبؤات DINOv2 وVLM ودرجاتها ونتائج API الخام كما هي. لا تعني هذه
السياسة إعادة تدريب تلقائية، ولا تغييرًا في استدلال الإنتاج أو في الملفات
الأصلية أو OOD Final Test. النتائج التاريخية تبقى محفوظة مع مرجعها القديم؛
لا تُقدّم على أنها نتائج محسوبة وفق آخر مراجعات المستخدم.

مسار التسجيل يعيد بناء مراجع النتائج والتقارير المحلية المسجلة تلقائيًا، دون
إعادة استدلال. يحدد `active_references.json` الملفات المشتقة الحالية؛ لا يُستخدم
ملف مشتق إذا كانت حالته `refresh_required` أو لم تطابق بصمة السجل الحالي.
ملفات CSV القديمة تبقى أدلة تاريخية، ولا تُستخدم أعمدة صحتها القديمة كمرجع حالي.
